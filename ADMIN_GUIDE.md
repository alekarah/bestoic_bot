## Управление книгами

### Добавить книгу

```bash
python admin.py book add путь/к/файлу.txt
```

**Интерактивный режим:**
- Программа спросит **название книги**
- Затем **автора**
- И **категорию**

**Категорию можно ввести:**
- Полностью: `теория`, `практика`, `цитаты`
- На английском: `theory`, `practice`, `quotes`
- Коротко: `t`, `p`, `q`

**Пример:**
```bash
$ python admin.py book add data/seneca.txt
Название книги: Нравственные письма к Луцилию
Автор: Сенека
Категория [Теория (t) / Практика (p) / Цитаты (q)]: t

✓ Книга "Нравственные письма к Луцилию" добавлена (ID: 1)
✓ Добавлено 45 цитат из категории "Теория"
✓ Всего обработано 50 абзацев
```

### Показать список книг

```bash
python admin.py book list
```

Вывод:
```
================================================================================
ID    Название                                 Автор                     Дата
================================================================================
1     Нравственные письма к Луцилию            Сенека                    2026-01-02
2     Размышления                              Марк Аврелий              2026-01-02
================================================================================
```

### Удалить книгу

```bash
python admin.py book delete <ID>
```

**Важно:** При удалении книги все связанные с ней цитаты остаются в базе, но теряют привязку к книге.

## Управление цитатами

### Добавить цитату вручную

```bash
python admin.py quote add
```

**Интерактивный режим:**
```bash
Текст цитаты (можно с атрибуцией через - Автор / Источник): Всё в твоих руках

— Эпиктет / Энхиридион

Категория [Теория (t) / Практика (p) / Цитаты (q)]: q

✓ Цитата добавлена (ID: 15) в категорию "Цитаты"
  Автор: Эпиктет
  Источник: Энхиридион
```

### Показать все цитаты

```bash
python admin.py quote list
```

**С фильтром по категории:**
```bash
python admin.py quote list --category theory
python admin.py quote list --category practice
python admin.py quote list --category quotes
```

**С ограничением количества:**
```bash
python admin.py quote list --limit 10
```

### Посмотреть полный текст цитаты

```bash
python admin.py quote view <ID>
```

**Пример вывода:**
```
================================================================================
ID: 1
Категория: Цитаты
Книга: Примеры - Сенека
Атрибуция: Сенека / Нравственные письма к Луцилию
--------------------------------------------------------------------------------
Всегда в смятении человек, который тревожится за будущее, Ни на час он не будет
спокоен и в ожидании будущего потеряет нынешнее, чем мог бы наслаждаться.
================================================================================
```

### Редактировать цитату

```bash
python admin.py quote edit <ID>
```

**Пример:**
```bash
$ python admin.py quote edit 1
Новый текст цитаты (можно с атрибуцией): Измененный текст цитаты

— Новый Автор / Новый источник

Новая категория [Теория (t) / Практика (p) / Цитаты (q)]: p

✓ Цитата ID:1 обновлена (категория: Практика)
  Автор: Новый Автор
  Источник: Новый источник
```

### Удалить цитату

```bash
python admin.py quote delete <ID>
```

Потребуется подтверждение:
```bash
Вы уверены? [y/N]: y
✓ Цитата ID:1 удалена
```

## Категории

### Три основные категории:

| Категория | Английский | Короткий | Описание |
|-----------|-----------|----------|----------|
| **Теория** | theory | t | Философские концепции и теоретические основы стоицизма |
| **Практика** | practice | p | Практические упражнения и техники для применения в жизни |
| **Цитаты** | quotes | q | Вдохновляющие и мотивирующие высказывания |

### Примеры ввода категории:

Все эти варианты эквивалентны:
- `теория` = `theory` = `t`
- `практика` = `practice` = `p`
- `цитаты` = `quotes` = `q`

**Рекомендация:** Используйте короткий вариант (`t`, `p`, `q`) для быстрого ввода.

## Форматирование цитат

### Автоматическое извлечение автора и источника

При загрузке книги или добавлении цитаты вручную, программа **автоматически** распознает атрибуцию.

### Поддерживаемые форматы:

**1. С длинным тире (—):**
```
Текст цитаты здесь.

— Сенека / Нравственные письма к Луцилию
```

**2. С дефисом (-):**
```
Текст цитаты здесь.

- Марк Аврелий / Размышления
```

**3. Без префикса:**
```
Текст цитаты здесь.

Эпиктет / Беседы
```

**4. Через запятую:**
```
Текст цитаты здесь.

Сенека, Письмо 98
```

### Формат текстового файла с книгой:

**С атрибуцией в каждой цитате:**
```
Первая мудрая мысль стоика.

— Сенека / Нравственные письма


Вторая мудрая мысль.

— Марк Аврелий / Размышления


Третья цитата без атрибуции будет привязана к названию книги.
```

**Простой формат (без атрибуции):**
```
Первая цитата.

Вторая цитата.

Третья цитата.
```

В этом случае будет использоваться название книги и автор, указанные при загрузке.

### Разделение цитат:

- **Двойной перенос строки** (`\n\n`) - стандартный разделитель
- **Тройной перенос строки** (`\n\n\n`) - для более четкого разделения

**Важно:**
- Абзацы короче 50 символов автоматически пропускаются (чтобы исключить заголовки)
- Пустая строка между текстом цитаты и атрибуцией обязательна

## Примеры использования

### Пример 1: Загрузка книги целиком

У вас есть файл `seneca_letters.txt`:

```
Жизнь разделяется на три периода: настоящее, прошлое и будущее. Из них настоящее кратко, будущее сомнительно, прошлое несомненно.

— Сенека / Нравственные письма к Луцилию


Не тот беден, у кого мало, а тот, кто хочет большего.

— Сенека / Нравственные письма к Луцилию
```

**Команда:**
```bash
python admin.py book add data/seneca_letters.txt
```

**Результат:**
- Книга "Нравственные письма к Луцилию" добавлена
- Автор каждой цитаты: Сенека
- Источник каждой цитаты: Нравственные письма к Луцилию
- Категория: выбрана при добавлении (например, `t` для теории)

### Пример 2: Быстрое добавление одной цитаты

```bash
python admin.py quote add
```

Вводим:
```
Текст: Главное не то, что с тобой происходит, а то, как ты на это реагируешь

— Эпиктет

Категория: q
```

### Пример 3: Просмотр цитат по категории

Посмотреть только теоретические цитаты:
```bash
python admin.py quote list --category theory --limit 5
```

### Пример 4: Редактирование категории цитаты

Цитата изначально была в категории "Цитаты", но вы решили что это "Теория":

```bash
python admin.py quote edit 5
```

Можно оставить текст прежним, изменив только категорию на `t`.

## Советы и рекомендации

### При загрузке книг:

✅ **Делайте:**
- Проверяйте кодировку файла (должна быть UTF-8)
- Убедитесь что цитаты разделены пустыми строками
- Указывайте автора и источник в самой цитате для точности

❌ **Избегайте:**
- Загрузки файлов с большим количеством коротких абзацев (заголовки, номера страниц)
- Смешивания категорий в одном файле (лучше разделить по файлам)

### При добавлении цитат вручную:

✅ **Делайте:**
- Используйте короткие варианты категорий (`t`, `p`, `q`) для скорости
- Указывайте атрибуцию через разделители для автоматического парсинга
- Проверяйте цитату командой `quote view` после добавления

### Резервное копирование:

База данных хранится в файле `bestoic_bot.db`. Регулярно делайте его резервные копии:

```bash
cp bestoic_bot.db bestoic_bot_backup_$(date +%Y%m%d).db
```

## Troubleshooting

### Проблема: Цитата не добавляется из файла

**Решение:**
- Проверьте что абзац длиннее 50 символов
- Убедитесь что используется двойной перенос строки между цитатами
- Проверьте кодировку файла (должна быть UTF-8)

### Проблема: Атрибуция не распознается

**Решение:**
- Убедитесь что между текстом цитаты и атрибуцией есть пустая строка
- Используйте правильный разделитель: `/` или `,`
- Проверьте наличие префикса `—` или `-` перед атрибуцией

### Проблема: Ошибка категории

**Решение:**
- Используйте только допустимые значения: `t`, `p`, `q` или `theory`, `practice`, `quotes`
- Категория регистронезависима: `T` = `t`
