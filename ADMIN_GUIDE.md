## Управление книгами

### Добавить книгу с цитатами

```bash
python admin.py book add путь/к/файлу.txt
```

**Интерактивный режим:**
- Программа спросит **название книги**
- Затем **автора**
- И **категорию**

**Категорию можно ввести:**
- Полностью: `цитаты`, `дейли`
- На английском: `quotes`, `daily`
- Коротко: `q`, `d`

**Пример:**
```bash
$ python admin.py book add data/seneca.txt
Название книги: Нравственные письма к Луцилию
Автор: Сенека
Категория [Цитаты (q) / Стоицизм на каждый день (d)]: q

✓ Книга "Нравственные письма к Луцилию" добавлена (ID: 1)
✓ Добавлено 45 цитат из категории "Цитаты"
✓ Всего обработано 50 абзацев
```

### Добавить книгу "Стоицизм на каждый день" (daily)

**Важно:** Для книг в формате "Стоицизм на каждый день" (с 366 записями по дням года) используйте специальную команду:

```bash
python admin.py book add-daily data/Райан-Холидей-Стоицизм-на-каждый-день.txt
```

Эта команда:
- Парсит записи по датам (1 ЯНВАРЯ, 2 ЯНВАРЯ, ..., 31 ДЕКАБРЯ)
- Извлекает заголовок, цитату, атрибуцию и размышление для каждого дня
- Автоматически привязывает записи к дням года (1-366)
- Категория устанавливается автоматически как `daily`

**Пример:**
```bash
$ python admin.py book add-daily data/daily_stoicism.txt
Название книги: Стоицизм на каждый день
Автор: Райан Холидей

✓ Книга "Стоицизм на каждый день" добавлена (ID: 12)
Парсинг записей по датам...
✓ Добавлено 366 записей из категории "Стоицизм на каждый день"
✓ Всего обработано 366 записей
```

**Формат файла:** См. [data/README.md](data/README.md#специальный-формат-для-категории-стоицизм-на-каждый-день-daily)

### Удалить книгу

```bash
python admin.py book delete <ID>
```

Программа покажет информацию о книге и количество цитат, затем предложит два варианта:

**Вариант 1: Удалить только книгу** (по умолчанию)
- Цитаты остаются в базе
- Теряют привязку к книге (book_id = NULL)
- Остаются доступны для бота

**Вариант 2: Удалить книгу вместе с цитатами**
- Книга и все её цитаты удаляются навсегда
- Используйте если цитаты больше не нужны

**Пример:**
```bash
$ python admin.py book delete 3

Книга: Размышления - Марк Аврелий
Цитат в книге: 45

Вы уверены что хотите удалить эту книгу? [y/N]: y

Удалить также все цитаты из этой книги? [y/N]: n
✓ Книга ID:3 удалена (цитаты сохранены без привязки к книге)
```

## Управление цитатами

### Добавить цитату вручную

```bash
python admin.py quote add
```

**Интерактивный режим:**
```bash
Текст цитаты (можно с атрибуцией через - Автор / Источник): Всё в твоих руках

— Эпиктет / Энхиридион

Категория [Цитаты (q) / Стоицизм на каждый день (d)]: q

✓ Цитата добавлена (ID: 15) в категорию "Цитаты"
  Автор: Эпиктет
  Источник: Энхиридион
```

### Показать все цитаты

```bash
python admin.py quote list
```

**С фильтром по категории:**
```bash
python admin.py quote list --category quotes
python admin.py quote list --category daily
```

**С ограничением количества:**
```bash
python admin.py quote list --limit 10
```

**С поиском по тексту:**
```bash
python admin.py quote list --search "препятствие"
python admin.py quote list -s "Эпиктет"
```

**Комбинированные фильтры:**
```bash
python admin.py quote list --category quotes --limit 10 --search "мудрость"
python admin.py quote list -c daily -l 5 -s "контроль"
```

### Посмотреть полный текст цитаты


**Пример вывода:**

### Найти дубликаты

Поиск похожих цитат с использованием алгоритма TF-IDF (быстро и эффективно):

```bash
python admin.py quote find-duplicates [--threshold 90]
```

**Параметры:**
- `--threshold` - порог схожести от 0 до 100 (по умолчанию 90%)

**Процесс:**
1. Векторизация всех цитат
2. Вычисление схожести между цитатами
3. Интерактивный выбор действия для каждой пары дубликатов

**Пример вывода:**
```bash
🔍 Поиск похожих цитат (порог схожести: 90%)...
Всего цитат: 150

Векторизация текстов...
Вычисление схожести...
Прогресс: 100%

✓ Проверка завершена

Найдено 2 пары похожих цитат:

================================================================================
Пара #1 (схожесть 95%):
--------------------------------------------------------------------------------
[1] ID: 12 | Категория: Цитаты
    Книга: Размышления - Марк Аврелий
    Текст: Препятствие на пути становится самим путём...

[2] ID: 45 | Категория: Цитаты
    Книга: Ручные цитаты (CLI) - Разное
    Текст: Препятствие на пути — это и есть путь...

Действие: [1] Оставить только ID:12  [2] Оставить только ID:45  [B] Оставить обе  [S] Пропустить [B]: 1
✓ Цитата ID:45 удалена
```

**Требования:**
- Библиотека `scikit-learn`: `pip install scikit-learn`

## Управление цитатами через Telegram

Администраторы могут управлять цитатами прямо через Telegram бот, без необходимости использовать CLI.

### Доступ

Админские команды доступны только пользователям, указанным в `ADMIN_USER_IDS` в `.env` файле.

Вы можете назначить:
- **Одного администратора:** `ADMIN_USER_IDS=123456789`
- **Нескольких администраторов:** `ADMIN_USER_IDS=123456789,987654321` (через запятую)

Все администраторы имеют полный доступ ко всем админским командам.

### Команды

#### Добавить цитату

```
/admin_add
```

**Процесс:**
1. Отправьте текст цитаты
2. Опционально укажите атрибуцию в формате: `— Автор / Источник / Книга / Глава`
3. Выберите категорию из кнопок
4. Система автоматически проверит дубликаты

**Пример:**
```
> /admin_add
Бот: 📝 Добавление новой цитаты
     Отправьте текст цитаты...

> Всё в твоих руках
> — Эпиктет / Энхиридион

Бот: 📝 Цитата получена:
     Всё в твоих руках

     📌 Атрибуция:
     Автор: Эпиктет
     Источник: Энхиридион

     Выберите категорию:
     [💭 Цитаты] [📅 Стоицизм на каждый день] [❌ Отменить]

> [нажимаем 💭 Цитаты]

Бот: ✅ Цитата добавлена!
     ID: 123
     Категория: Цитаты
```

#### Редактировать цитату

```
/admin_edit
```

**Процесс:**
1. Отправьте ID цитаты или часть текста для поиска
2. Если найдено несколько цитат, выберите нужную из списка
3. Выберите поле для редактирования (текст, категория, автор, источник)
4. Введите новое значение или выберите из кнопок
5. Можно изменить несколько полей подряд
6. Нажмите "✅ Готово" когда закончите

**Пример:**
```
> /admin_edit
Бот: ✏️ Редактирование цитаты
     Отправьте ID цитаты или часть текста для поиска

> 123

Бот: ✏️ Редактирование цитаты ID:123
     📂 Категория: Цитаты
     📌 Атрибуция:
     Автор: Эпиктет
     Источник: Энхиридион

     💬 Текст:
     Всё в твоих руках

     Что хотите изменить?
     [📝 Текст] [📂 Категория] [👤 Автор] [📖 Источник] [✅ Готово]

> [нажимаем 📂 Категория]

Бот: 📂 Выберите новую категорию:
     [💭 Цитаты] [📅 Стоицизм на каждый день] [❌ Отменить]

> [нажимаем 📅 Стоицизм на каждый день]

Бот: ✅ Значение обновлено!
     [показывает обновлённое меню редактирования]
```

#### Удалить цитату

```
/admin_delete
```

**Процесс:**
1. Отправьте ID цитаты или часть текста для поиска
2. Если найдено несколько цитат, выберите нужную из списка
3. Подтвердите удаление

**Пример:**
```
> /admin_delete
Бот: 🗑 Удаление цитаты
     Отправьте ID цитаты или часть текста для поиска

> 123

Бот: 📋 Найдена цитата:
     ID: 123
     Категория: Цитаты

     Всё в твоих руках

     Удалить эту цитату?
     [✅ Да, удалить] [❌ Отменить]

> [нажимаем ✅ Да, удалить]

Бот: ✅ Цитата ID:123 удалена!
```


Показывает топ цитат, которые пользователи добавляют в избранное:
- Топ-10 цитат с количеством добавлений

- Общую статистику (процент цитат в избранном)

### Поиск цитат

Для команд `/admin_edit` и `/admin_delete` можно искать цитаты:
- **По ID**: `123` - найдёт точную цитату
- **По тексту**: `в твоих руках` - найдёт все цитаты содержащие этот текст

Если найдено более 10 цитат, бот попросит уточнить запрос.

### Отмена операции

В любой момент можно отправить:
```
/cancel
```

Это прервёт текущую операцию добавления, редактирования или удаления.

### Особенности

- ✅ Автоматическая проверка дубликатов при добавлении
- ✅ Поддержка атрибуции (автор/источник) в формате CLI
- ✅ Удобный поиск по ID или тексту
- ✅ Интерактивное меню с кнопками
- ✅ Защита от случайного удаления
- ⚠️ Доступ только для администратора

## Библиотека книг для скачивания

Библиотека позволяет добавлять книги в разных форматах (fb2, epub, mobi, pdf) для скачивания пользователями через команду `/books`.

### Подготовка: Загрузка файлов на сервер

**Если работаете на удаленном сервере**, сначала нужно загрузить файлы книг на сервер.

#### Шаг 0: Создайте папку для книг (если её нет)

```bash
ssh root@YOUR_SERVER_IP
mkdir -p /home/botuser/bestoic_bot/data/books
exit
```

Или проверьте, что папка существует:
```bash
ssh root@YOUR_SERVER_IP "ls -la /home/botuser/bestoic_bot/data/"
```

Исправь владельца папки, если необходимо с root на botuser:
```bash
chown -R botuser:botuser /home/botuser/bestoic_bot/data/books
```

#### Вариант 1: Через SCP (рекомендуется)

```bash
# Загрузить один файл
scp "path/to/book.fb2" root@YOUR_SERVER_IP:/home/botuser/bestoic_bot/data/books/

# Загрузить несколько файлов
scp "path/to/book1.fb2" "path/to/book2.epub" root@YOUR_SERVER_IP:/home/botuser/bestoic_bot/data/books/

# Загрузить все файлы из папки
scp path/to/books/* root@YOUR_SERVER_IP:/home/botuser/bestoic_bot/data/books/
```

**Для Windows PowerShell:**
```powershell
# Один файл
scp "D:\books\Сенека-Письма.fb2" root@YOUR_SERVER_IP:/home/botuser/bestoic_bot/data/books/

# Все файлы из папки (без кавычек для маски)
scp D:\books\* root@YOUR_SERVER_IP:/home/botuser/bestoic_bot/data/books/
```

#### Вариант 2: Через SFTP

```bash
sftp root@YOUR_SERVER_IP
cd /home/botuser/bestoic_bot/data/books
put "path/to/book.fb2"
exit
```

#### Вариант 3: Через Git (если файлы небольшие)

```bash
# Локально добавить файлы в git
git add data/books/*.fb2
git commit -m "Add book files"
git push

# На сервере
git pull
```

### Добавить книгу в библиотеку

```bash
python admin.py library add
```

**Интерактивный режим:**
- Название книги
- Автор
- Описание (можно пустое)
- Ссылка на покупку бумажной версии (можно пустое)

**Пример:**
```bash
$ python admin.py library add
Автор: Марк Аврелий
Название книги: Размышления
Описание (можно пустое): Классический текст римского императора и философа-стоика

✓ Книга "Марк Аврелий — Размышления" добавлена в библиотеку (ID: 1)
  Теперь добавьте файлы: python admin.py library add-file 1 <путь_к_файлу>
```

```bash
python admin.py library add-file <ID> <путь_к_файлу>
```

### Установить порядок отображения книги

Эта команда позволяет управлять порядком, в котором книги показываются пользователям в Telegram. Книги с меньшим номером отображаются первыми.

- Книги с меньшим номером показываются первыми

- В команде `library list` порядок отображается в колонке "Порядок"

### Как пользователи скачивают книги

Пользователи используют команду `/books` в Telegram:

1. Открывается список книг с пагинацией
2. Можно отфильтровать по автору (кнопка "👤 По авторам")
3. При нажатии на книгу открывается страница с описанием
4. Кнопки форматов (FB2, EPUB, PDF, MOBI) для скачивания
5. Кнопка "🛒 Купить бумажную версию" (если указана ссылка)

**Кэширование:** После первой отправки файла сохраняется `file_id` Telegram. Повторные скачивания происходят мгновенно без повторной загрузки файла на серверы Telegram.

### Полный рабочий процесс (работа с сервером)

**Шаг 1: Убедиться, что папка существует**
```bash
# Проверить, есть ли папка
ssh root@YOUR_SERVER_IP "ls -la /home/botuser/bestoic_bot/data/"

# Если нет, создать
ssh root@YOUR_SERVER_IP "mkdir -p /home/botuser/bestoic_bot/data/books"
```

**Шаг 2: Загрузить файлы книги на сервер**
```bash
# С локального компьютера загрузить файлы на сервер
scp "D:\books\Сенека-Письма.fb2" root@YOUR_SERVER_IP:/home/botuser/bestoic_bot/data/books/
scp "D:\books\Сенека-Письма.epub" root@YOUR_SERVER_IP:/home/botuser/bestoic_bot/data/books/
```

**Шаг 3: Подключиться к серверу**
```bash
ssh root@YOUR_SERVER_IP
cd /home/botuser/bestoic_bot
```

**Шаг 4: Добавить книгу в библиотеку**
```bash
python admin.py library add
# Ввести автора, название, описание, ссылку на покупку
```

**Шаг 5: Добавить файлы книги**
```bash
# Запомните ID книги из предыдущего шага
python admin.py library add-file 1 data/books/Сенека-Письма.fb2
python admin.py library add-file 1 data/books/Сенека-Письма.epub
```

**Шаг 6: Проверить**
```bash
python admin.py library list
python admin.py library view 1
```

**Готово!** Теперь книга доступна пользователям через `/books` в Telegram.

#### Альтернатива: Работа через Git

Если файлы небольшие (до 50MB), можно работать локально и пушить через Git:

```bash
# Локально

python admin.py library add-file 1 data/books/book.fb2  # Добавить файлы

git pull
# Бот автоматически увидит новую книгу
```

## Категории

### Две основные категории:

| Категория | Английский | Короткий | Описание |
|-----------|-----------|----------|----------|
| **Цитаты** | quotes | q | Вдохновляющие мысли стоиков |
| **Стоицизм на каждый день** | daily | d | Ежедневные размышления (366 дней в году) |

### Примеры ввода категории:

Все эти варианты эквивалентны:
- `цитаты` = `quotes` = `q`
- `дейли` = `daily` = `d`

**Рекомендация:** Используйте короткий вариант (`q`, `d`) для быстрого ввода.

**Важно:** Для категории "Стоицизм на каждый день" цитаты должны быть организованы по дням года (1-366). См. [форматирование для daily категории](../data/README.md).

## Форматирование цитат

Программа автоматически извлекает автора и источник из текста цитаты.

**📄 Полное руководство по формату книг:** [data/README.md](../data/README.md)

**Образец файла:** [data/example_quote.txt](../data/example_quote.txt)

### Краткая справка:

- Файл `.txt` в кодировке UTF-8
- Три пустые строки между цитатами
- Атрибуция в конце: `— Автор / Источник`
- Поддерживаются форматы: `— Автор / Источник`, `- Автор, Источник`, и др.

## Troubleshooting

### Цитата не добавляется из файла
- Проверьте кодировку (UTF-8)
- Убедитесь что абзац длиннее 50 символов
- Три пустые строки между цитатами

### Атрибуция не распознается
- Пустая строка перед атрибуцией обязательна
- Используйте разделитель `/` или `,`
- См. [data/README.md](../data/README.md) для примеров

### Ошибка категории
- Допустимые значения: `q` (цитаты), `d` (daily) - регистронезависимо
