# Инструкция по установке и запуску Bestoic Bot

## Требования

- Python 3.10 или выше
- Telegram Bot Token (получить у @BotFather)
- Ваш Telegram User ID (получить у @userinfobot)

## Установка

### 1. Клонировать репозиторий

```bash
git clone <repository-url>
cd bestoic_bot
```

### 2. Создать виртуальное окружение

```bash
python -m venv venv
```

### 3. Активировать виртуальное окружение

**Windows:**
```bash
venv\Scripts\activate
```

**Linux/Mac:**
```bash
source venv/bin/activate
```

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

### 5. Настроить переменные окружения

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Отредактируйте `.env` файл и добавьте:
- `TELEGRAM_BOT_TOKEN` - токен вашего бота от @BotFather
- `ADMIN_USER_IDS` - ваш Telegram User ID (или несколько ID через запятую) от @userinfobot

```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# Один администратор:
ADMIN_USER_IDS=123456789

# Или несколько администраторов (через запятую):
ADMIN_USER_IDS=123456789,987654321
```

**Примечание:** Старый формат `ADMIN_USER_ID` также поддерживается для обратной совместимости.

## Использование

### Запуск бота

```bash
python bot.py
```

Бот будет работать 24/7 и автоматически отправлять цитаты в назначенное время.

### Управление цитатами (Admin CLI)

#### Статистика

```bash
python admin.py stats
```

#### Управление книгами

**Добавить книгу:**
```bash
python admin.py book add путь/к/файлу.txt
```

Программа запросит:
- Название книги
- Автора
- Категорию (theory/practice/quotes)

**Список всех книг:**
```bash
python admin.py book list
```

**Удалить книгу:**
```bash
python admin.py book delete <ID>
```

#### Управление цитатами

**Добавить цитату вручную:**
```bash
python admin.py quote add
```

**Показать все цитаты:**
```bash
python admin.py quote list
```

**Показать цитаты по категории:**
```bash
python admin.py quote list --category theory
python admin.py quote list --category practice
python admin.py quote list --category quotes
```

**Посмотреть полный текст цитаты:**
```bash
python admin.py quote view <ID>
```

**Редактировать цитату:**
```bash
python admin.py quote edit <ID>
```

**Удалить цитату:**
```bash
python admin.py quote delete <ID>
```

## Формат книг для загрузки

Книги должны быть в текстовом формате (UTF-8), где цитаты разделены двумя или тремя переносами строк (пустыми строками).

### Формат с атрибуцией (рекомендуется)

Программа автоматически распознает автора и источник цитаты, если они указаны в конце через разделитель:

```
Всегда в смятении человек, который тревожится за будущее, Ни на час он не будет спокоен и в ожидании будущего потеряет нынешнее, чем мог бы наслаждаться. Ведь жалеть о потерянной вещи и бояться ее потерять – это одно и то же.

— Сенека / Нравственные письма к Луцилию


Следующая цитата здесь...

— Эпиктет / Беседы
```

**Поддерживаемые форматы атрибуции:**
- `— Автор / Источник` (тире с пробелом)
- `- Автор / Источник` (дефис с пробелом)
- `Автор / Источник` (без префикса)
- `Автор, Источник` (через запятую)

### Простой формат

Можно загружать цитаты без атрибуции - в этом случае будет использоваться информация о книге:

```
Первая цитата или абзац с мудростью стоиков.

Вторая цитата, которая будет автоматически добавлена в базу.

Третья цитата...
```

**Важно:**
- Программа автоматически пропускает короткие абзацы (менее 50 символов), чтобы исключить заголовки и служебную информацию
- При использовании тройных переносов строк (`\n\n\n`) цитаты разделяются более чётко
- Приоритет отображения: атрибуция из самой цитаты → информация о книге

## Команды бота для пользователей

- `/start` - начать работу с ботом
- `/quote` - получить случайную цитату прямо сейчас
- `/settings` - настроить категорию цитат и время получения
- `/help` - справка по командам

## Категории цитат

- **Теория** - философские концепции и теоретические основы стоицизма
- **Практика** - практические упражнения и техники для применения в жизни
- **Цитаты** - вдохновляющие и мотивирующие высказывания
- **Все категории** - случайная цитата из любой категории

## Время отправки

Пользователи могут выбрать одно из трех времен для получения ежедневных цитат:
- **Утро** - 8:00
- **День** - 14:00
- **Вечер** - 20:00

## Troubleshooting

### Бот не отправляет сообщения

Проверьте:
1. Правильность токена бота в `.env`
2. Что бот запущен (`python bot.py`)
3. Что пользователь активировал уведомления в `/settings`

### Ошибки при загрузке книги

Проверьте:
1. Кодировка файла должна быть UTF-8
2. Файл существует и путь указан правильно
3. В файле есть текст, разделенный пустыми строками

### База данных не создается

Убедитесь, что у вас есть права на запись в директорию проекта.
