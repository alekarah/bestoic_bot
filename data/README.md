# Формат книг для загрузки

Полное руководство по подготовке текстовых файлов с цитатами для загрузки в бот.

## Образец файла

📄 **[example_quote.txt](example_quote.txt)** - готовый пример с 6 цитатами, демонстрирующий все варианты форматирования.

---

## Требования к файлу

- **Формат:** `.txt` (текстовый файл)
- **Кодировка:** UTF-8 (обязательно!)
- **Разделитель цитат:** Три пустые строки (`\n\n\n`) между цитатами
- **Длина цитаты:**
  - Минимум: 50 символов (короткие абзацы пропускаются)
  - **Рекомендуемый размер: 150-500 символов** (2-4 предложения, умещается на экране)
  - Приемлемо: 500-1000 символов (требует концентрации)
  - Технический лимит: ~3500 символов (лимит Telegram - 4096 символов на сообщение)

## Полный пример файла

```
Лучше всего начинать день с размышления о том, что ты не можешь контролировать внешние события, но можешь контролировать свою реакцию на них.

— Эпиктет / Беседы


Препятствие на пути становится самим путём. Никогда не забывай: в каждом препятствии скрыта возможность улучшить что-то или чему-то научиться.

— Марк Аврелий / Размышления


Мы страдаем больше в воображении, чем в реальности.

— Сенека / Нравственные письма к Луцилию


Цитата без атрибуции будет привязана к названию книги и автору, указанным при загрузке.
```

---

## Структура одной цитаты

### С атрибуцией (рекомендуется):
```
Текст цитаты может занимать несколько абзацев.

Второй абзац той же цитаты.

— Автор / Источник
```

### Без атрибуции:
```
Текст цитаты здесь.
```

**Между цитатами - три пустые строки (два перевода строки подряд).**

---

## Разделение цитат

- **Основной разделитель:** Три пустые строки (`\n\n\n`) между цитатами
- **Внутри цитаты:** Двойной перенос строки (`\n\n`) для разделения абзацев
- **Атрибуция:** Пустая строка перед строкой с автором/источником

**Важно:**
- Абзацы короче 50 символов автоматически **пропускаются** (чтобы исключить заголовки, номера страниц)
- Пустая строка между текстом цитаты и атрибуцией **обязательна**
- Приоритет отображения: атрибуция из цитаты → информация о книге

---

## Поддерживаемые форматы атрибуции

Программа автоматически извлекает автора и источник из следующих форматов:

| Формат | Пример | Результат |
|--------|--------|-----------|
| Длинное тире + слеш | `— Сенека / Нравственные письма` | Автор: Сенека<br>Источник: Нравственные письма |
| Дефис + слеш | `- Марк Аврелий / Размышления` | Автор: Марк Аврелий<br>Источник: Размышления |
| Без префикса + слеш | `Эпиктет / Беседы` | Автор: Эпиктет<br>Источник: Беседы |
| Через запятую | `Сенека, Письмо 98` | Автор: Сенека<br>Источник: Письмо 98 |
| Только автор | `— Эпиктет` | Автор: Эпиктет<br>Источник: (название книги) |

## Загрузка книги

```bash
python admin.py book add data/your_book.txt
```

Программа интерактивно запросит:
- **Название книги**
- **Автора**
- **Категорию** (t - теория, p - практика, q - цитаты)

**Пример:**
```bash
$ python admin.py book add data/seneca.txt
Название книги: Нравственные письма к Луцилию
Автор: Сенека
Категория [Теория (t) / Практика (p) / Цитаты (q)]: t

✓ Книга "Нравственные письма к Луцилию" добавлена (ID: 1)
✓ Добавлено 45 цитат из категории "Теория"
```

## Советы по подготовке файлов

### ✅ Делайте:
- Проверяйте кодировку файла (должна быть UTF-8)
- Убедитесь что цитаты разделены пустыми строками
- Указывайте автора и источник в самой цитате для точности
- Используйте длинное тире (—) для атрибуции

### ❌ Избегайте:
- Загрузки файлов с большим количеством коротких абзацев (заголовки, номера страниц)
- Смешивания категорий в одном файле (лучше разделить по файлам)
- Неправильной кодировки (не UTF-8)
