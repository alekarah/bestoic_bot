# Формат книг для загрузки

Полное руководство по подготовке текстовых файлов с цитатами для загрузки в бот.

## Образец файла

📄 **[example_quote.txt](example_quote.txt)** - готовый пример с 6 цитатами, демонстрирующий все варианты форматирования.

---

## Требования к файлу

- **Формат:** `.txt` (текстовый файл)
- **Кодировка:** UTF-8 (обязательно!)
- **Разделитель цитат:** Три пустые строки (`\n\n\n`) между цитатами
- **Длина цитаты:**
  - Минимум: 50 символов (короткие абзацы пропускаются)
  - **Рекомендуемый размер: 150-500 символов** (2-4 предложения, умещается на экране)
  - Приемлемо: 500-1000 символов (требует концентрации)
  - Технический лимит: ~3500 символов (лимит Telegram - 4096 символов на сообщение)

---

## Полный пример файла

```
Лучше всего начинать день с размышления о том, что ты не можешь контролировать внешние события, но можешь контролировать свою реакцию на них.

— Эпиктет / Беседы


Препятствие на пути становится самим путём. Никогда не забывай: в каждом препятствии скрыта возможность улучшить что-то или чему-то научиться.

— Марк Аврелий / Размышления


Мы страдаем больше в воображении, чем в реальности.

— Сенека / Нравственные письма к Луцилию


Цитата без атрибуции будет привязана к названию книги и автору, указанным при загрузке.
```

---

## Структура одной цитаты

### С атрибуцией (рекомендуется):
```
Текст цитаты может занимать несколько абзацев.

Второй абзац той же цитаты.

— Автор / Источник
```

### Без атрибуции:
```
Текст цитаты здесь.
```

**Между цитатами - три пустые строки (два перевода строки подряд).**

---

## Разделение цитат

- **Основной разделитель:** Три пустые строки (`\n\n\n`) между цитатами
- **Внутри цитаты:** Двойной перенос строки (`\n\n`) для разделения абзацев
- **Атрибуция:** Пустая строка перед строкой с автором/источником

**Важно:**
- Абзацы короче 50 символов автоматически **пропускаются** (чтобы исключить заголовки, номера страниц)
- Пустая строка между текстом цитаты и атрибуцией **обязательна**
- Приоритет отображения: атрибуция из цитаты → информация о книге

---

## Поддерживаемые форматы атрибуции

Программа автоматически извлекает автора и источник из следующих форматов:

| Формат | Пример | Результат |
|--------|--------|-----------|
| Длинное тире + слеш | `— Сенека / Нравственные письма` | Автор: Сенека<br>Источник: Нравственные письма |
| Дефис + слеш | `- Марк Аврелий / Размышления` | Автор: Марк Аврелий<br>Источник: Размышления |
| Без префикса + слеш | `Эпиктет / Беседы` | Автор: Эпиктет<br>Источник: Беседы |
| Через запятую | `Сенека, Письмо 98` | Автор: Сенека<br>Источник: Письмо 98 |
| Только автор | `— Эпиктет` | Автор: Эпиктет<br>Источник: (название книги) |

## Загрузка книги

```bash
python admin.py book add data/your_book.txt
```

Программа интерактивно запросит:
- **Название книги**
- **Автора**
- **Категорию** (t - теория, p - практика, q - цитаты)

**Пример:**
```bash
$ python admin.py book add data/seneca.txt
Название книги: Нравственные письма к Луцилию
Автор: Сенека
Категория [Теория (t) / Практика (p) / Цитаты (q)]: t

✓ Книга "Нравственные письма к Луцилию" добавлена (ID: 1)
✓ Добавлено 45 цитат из категории "Теория"
```

## Советы по подготовке файлов

### ✅ Делайте:
- Проверяйте кодировку файла (должна быть UTF-8)
- Убедитесь что цитаты разделены пустыми строками
- Указывайте автора и источник в самой цитате для точности
- Используйте длинное тире (—) для атрибуции

### ❌ Избегайте:
- Загрузки файлов с большим количеством коротких абзацев (заголовки, номера страниц)
- Смешивания категорий в одном файле (лучше разделить по файлам)
- Неправильной кодировки (не UTF-8)

### 📝 Сокращение длинных цитат

Если цитата слишком длинная, можно пропустить середину, сохранив начало и конец:

**Используйте `<…>` для обозначения пропуска:**

```
Ты говоришь, что ты перестал стараться о своем улучшении <…> Опомнись, несчастный друг мой, и спаси себя от самого себя.

— Эпиктет / В чем наше благо
```

**Правила:**
- Пробелы вокруг: `текст <…> текст`
- Не более 1-2 пропусков на цитату
- Сохраняйте логическую связь и смысл
- Начало и конец должны образовывать связное высказывание

**Работа с заголовками:**

Если в книге есть заголовки разделов, используйте гибридный подход:

1. **Для длинных цитат (>500 символов):**
   - Включите заголовок как первую строку цитаты
   - Это даст необходимый контекст
   ```
   К другу, вернувшемуся к развратной жизни

   Опомнись, несчастный друг мой <…> Разбери хорошенько самого себя.

   — Эпиктет / В чем наше благо
   ```

2. **Для коротких цитат (<500 символов):**
   - Добавьте заголовок в атрибуцию:
   ```
   Опомнись и спаси свою душу!

   — Эпиктет / В чем наше благо: К другу, вернувшемуся к развратной жизни
   ```

3. **Если заголовок общий** (типа "О добродетели"):
   - Можно пропустить — смысл и так понятен

## Специальный формат для категории "Стоицизм на каждый день" (daily)

Для категории **daily** используется особый формат, организующий цитаты по дням года (1-366).

📄 **[example_daily.txt](example_daily.txt)** - пример файла с цитатами для категории daily (3 дня).

### Структура файла:

```
1 ЯНВАРЯ
Заголовок дня

Текст цитаты (без пустых строк внутри абзаца).

Автор / Источник

Текст размышления или комментария к цитате. Это может быть длинный текст без пустых строк между предложениями.


2 ЯНВАРЯ
Следующий заголовок

Следующая цитата...

Автор / Источник

Размышление...
```

### Правила форматирования:

1. **Заголовок даты:** Формат `ДЕНЬ МЕСЯЦ` заглавными буквами (например, `15 МАРТА`, `29 ФЕВРАЛЯ`)
   - Поддерживается високосный год (29 февраля)
   - Месяцы на русском языке

2. **Структура записи для каждого дня:**
   - Заголовок дня (тема размышления)
   - Пустая строка
   - Текст цитаты (без пустых строк внутри)
   - Пустая строка
   - Атрибуция (Автор / Источник)
   - Пустая строка
   - Текст размышления (без пустых строк внутри)
   - **Две пустые строки** перед следующей датой

3. **Несколько цитат:** Если в записи дня есть две цитаты, каждая имеет свою атрибуцию:
   ```
   Первая цитата...

   Автор1 / Источник1

   Вторая цитата...

   Автор2 / Источник2

   Размышление...
   ```

4. **Формат атрибуции:** Такой же, как для обычных цитат (см. выше)

### Пример файла daily:

```
1 ЯНВАРЯ
Контроль своих реакций

Лучше всего начинать день с размышления о том, что ты не можешь контролировать внешние события, но можешь контролировать свою реакцию на них.

Эпиктет / Беседы

Каждое утро напоминай себе: события дня не в твоей власти, но твое отношение к ним — полностью в твоих руках.


2 ЯНВАРЯ
Препятствия как возможности

Препятствие на пути становится самим путём. Никогда не забывай: в каждом препятствии скрыта возможность улучшить что-то или чему-то научиться.

Марк Аврелий / Размышления

Когда встречаешь трудность, спроси себя: чему она может меня научить?
```

### Загрузка файла daily:

**Важно:** Для книг в формате daily используйте специальную команду `book add-daily`:

```bash
python admin.py book add-daily data/daily_stoicism.txt
```

При загрузке программа запросит:
- **Название книги:** например, "Стоицизм на каждый день"
- **Автор:** автор/составитель книги

Категория `daily` устанавливается автоматически. Каждая запись привязывается к соответствующему дню года (1-366).
