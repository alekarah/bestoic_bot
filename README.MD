# Bestoic Bot

Telegram bot для ежедневной рассылки цитат из книг по стоицизму.

## Описание

Бот отправляет вдохновляющие цитаты из классических произведений стоической философии. Пользователи могут выбирать категории цитат и время получения уведомлений.

## Возможности

### Для пользователей:
- Получение ежедневных цитат по стоицизму
- Выбор категории:
  - **Теория** - философские концепции
  - **Практика** - практические упражнения
  - **Цитаты** - вдохновляющие фразы
  - **Все категории** - случайная цитата из любой категории
- Выбор времени получения:
  - Утро (8:00)
  - День (14:00)
  - Вечер (20:00)

### Для администратора:
- Загрузка книг с автоматическим разделением на цитаты
- Добавление, редактирование и удаление цитат
- Управление через CLI интерфейс

## Технологии

- Python 3.10+
- python-telegram-bot
- SQLite
- APScheduler
- Click
